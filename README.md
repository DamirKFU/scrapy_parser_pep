# 📘 Асинхронный парсер PEP (Scrapy)

## 📌 Описание проекта

Данный проект представляет собой асинхронный парсер PEP (Python Enhancement Proposals), реализованный с использованием фреймворка Scrapy.

Парсер автоматически обходит страницы сайта https://peps.python.org/ и собирает информацию о документах PEP, включая:

* номер PEP
* название
* статус документа

Также формируется агрегированная статистика по статусам всех PEP.

Проект демонстрирует:

* работу с асинхронным парсингом
* использование Scrapy (spiders, items, pipelines)
* сбор и агрегацию данных
* экспорт результатов в CSV

---

## ⚙️ Функциональность

Парсер выполняет:

* 🔎 сбор ссылок на все PEP-документы
* 📄 парсинг страниц PEP
* 📊 подсчёт количества PEP по статусам
* 💾 сохранение результатов в CSV

---

## 🛠️ Технологии

В проекте используются:

* Python 3.9
* Scrapy — асинхронный парсинг
* CSV — сохранение данных

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone git@github.com:DamirKFU/scrapy_parser_pep.git
cd scrapy_parser_pep
```

---

### 2. Создание виртуального окружения

```bash
python -m venv venv
source venv/bin/activate  # Linux / Mac
venv\Scripts\activate     # Windows
```

---

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

---

### 4. Запуск парсера

```bash
scrapy crawl pep
```

---

## 📤 Выходные данные

После выполнения парсера в директории `results/` создаются два файла:

---

### 📄 1. Список PEP

Файл вида:

```text
pep_YYYY-MM-DDTHH-MM-SS.csv
```

Содержит:

* Номер
* Название
* Статус

---

### 📊 2. Сводка по статусам

Файл вида:

```text
status_summary_YYYY-MM-DD_HH-MM-SS.csv
```

Содержит:

* Статус
* Количество

В последней строке:

* Статус = `Total`
* Количество = общее число PEP

---

## 🧩 Особенности реализации

* Используется `scrapy.Item` для описания структуры данных
* Сбор ссылок выполняется в методе `parse()`
* Парсинг PEP — в `parse_pep()`
* Сохранение списка PEP — через **Feeds (settings.py)**
* Сводка по статусам — через **Pipeline**
